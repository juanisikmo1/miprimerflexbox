Modelo de caja Box Model

Cada elemento HTML se representa como una caja rectangular. El modelo de caja explica cómo se organizan el contenido, el relleno, el borde y el margen de cada elemento.

¿Qué es el Box Model?

El Box Model o modelo de caja es un concepto fundamental de CSS. Permite controlar el espacio que ocupa cada elemento en una página. Está formado por cuatro partes: contenido (content), relleno (padding), borde (border) y margen (margin).

Para tener en cuenta: el tamaño total que ocupa un elemento depende de sus dimensiones, relleno, bordes y márgenes. Comprender estas partes ayuda a crear diseños ordenados y evitar problemas de espacio.

Las cuatro partes del modelo de caja

Cada parte cumple una función específica en la distribución del espacio:

1. Content

Es el contenido del elemento: texto, imágenes, videos u otros elementos HTML. Sus dimensiones se controlan con width y height.

2. Padding

Es el espacio interno entre el contenido y el borde. Permite separar el contenido de los límites de la caja.

3. Border

Es el borde que rodea el contenido y el padding. Se puede personalizar con grosor, estilo y color.

4. Margin

Es el espacio externo que separa una caja de otros elementos. Ayuda a controlar la distancia entre componentes.

Ejemplo práctico en CSS

Observa cómo se aplican las propiedades del Box Model a una caja:

.mi-caja {
  width: 300px;
  height: 150px;
  padding: 20px;
  border: 5px solid #55CC86;
  margin: 30px;
}

¿Qué hace este código?

Crea una caja con un contenido de 300 píxeles de ancho y 150 píxeles de alto, agrega 20 píxeles de espacio interno, un borde de 5 píxeles y una separación externa de 30 píxeles.

La propiedad box-sizing

content-box

Es el valor predeterminado. El ancho y alto definidos se aplican al contenido; el padding y el borde se suman al tamaño final.

border-box

El ancho y alto definidos incluyen el contenido, el padding y el borde. Facilita el control de las dimensiones de los elementos.

* {
  box-sizing: border-box;
}
